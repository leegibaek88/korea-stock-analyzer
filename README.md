# 추세·돌파형 한국주식 분석기

Minervini + O'Neil + Weinstein의 공개된 추세/돌파 투자 원칙을 가격, 이동평균, 거래량, 시장대비 상대강도 기준으로 조합한 Streamlit 분석 프로그램입니다.

이 프로그램은 자동 매매 프로그램이 아닙니다. 주문 기능, 증권사 로그인, 매수/매도 주문 API 연결은 포함하지 않습니다.

## 주요 기능

- 한국 주식 종목코드 6자리 또는 종목명 검색 분석
- KOSPI/KOSDAQ 시장지수 대비 상대강도 계산
- Minervini Trend Template 체크리스트
- Weinstein Stage 분석
- O'Neil 스타일 가격/거래량 돌파 분석
- VCP 유사패턴 탐지
- 종합점수, 최종등급, 현재 진입상태 분리 표시
- 추천 진입방식, 추천 매수가격대, 방어적 매도가격대, 분할 매도가격대 표시
- 개별 종목 차트 위에 회사정보 표시
- 투자자 게시판 데모와 회원가입 관심 등록
- 투자 기간·성향·자금·리스크 허용폭 기반 참여형 투자 시뮬레이션
- 과거 데이터에서 분석 조건 부합 후 상승한 사례를 블로그 글 형태로 표시
- 긍정 요소와 위험 요소 자동 생성
- Plotly 캔들차트 및 거래량 차트
- 현재 Streamlit 세션 내 최근 분석목록
- 최대 10개 종목 다중 비교
- KOSPI/KOSDAQ 각각 일간·주간·월간 추천 TOP10
- KOSPI/KOSDAQ 각각 일간·월간·연간 상승률 TOP10 및 하락률 TOP10
- KOSPI/KOSDAQ 각각 이상 급등/과열 주의 후보 TOP10
- TOP10 표에서 `개별 분석` 링크를 눌러 바로 종목 상세 분석 열기

## Windows 설치 방법

1. Python 3.11 이상을 설치합니다.

2. 터미널 또는 PowerShell에서 프로젝트 폴더로 이동합니다.

```powershell
cd "C:\Users\UserK\Documents\New project\stock_analyzer"
```

3. 필요한 패키지를 설치합니다.

```powershell
pip install -r requirements.txt
```

4. 프로그램을 실행합니다.

```powershell
streamlit run app.py
```

5. 브라우저가 열리면 종목코드 6자리 또는 종목명을 입력하고 분석합니다.

## 예시 종목코드

- 삼성전자: `005930`
- SK하이닉스: `000660`
- NAVER: `035420`
- 에코프로비엠: `247540`

종목명으로도 `삼성전자`, `SK하이닉스`, `NAVER`처럼 입력할 수 있습니다.

## 참고

- 종목코드는 문자열로 처리되어 `005930`처럼 앞자리 0이 유지됩니다.
- 데이터는 FinanceDataReader에서 가져오며, 데이터 제공 상태에 따라 일부 종목은 조회되지 않을 수 있습니다.
- 신규상장주처럼 데이터가 부족한 경우 200일선 관련 조건은 임의로 통과 처리하지 않고 `데이터 부족`으로 표시합니다.
- 모든 점수와 판정은 투자 참고용 분석이며, 수익을 보장하지 않습니다.
- 추천 매수가격대와 매도가격대는 추세, 돌파 기준, 이동평균, 최근 저점으로 계산한 참고 범위입니다. 확정 주문 신호가 아닙니다.
- 시장 전체 스캔 탭은 최초 실행 시 여러 종목의 데이터를 내려받기 때문에 몇 분 걸릴 수 있습니다. 결과는 캐시되어 반복 조회 속도가 빨라지고, 하루가 지나면 다시 갱신됩니다.
- 이상 급등/과열 주의 후보는 불공정거래나 작전주를 단정하지 않습니다. 거래량 급증, 단기 급등락, 이동평균 이격, 장중 변동성 같은 기술적 이상 징후를 기준으로 주의가 필요한 후보를 보여줍니다.
- 투자 시뮬레이션은 예측이나 수익 보장이 아니라, 기존 분석 결과를 바탕으로 진입·익절·방어 계획을 구성하는 참고 도구입니다.
- 과거 적중 사례는 백테스트 성격의 참고 자료이며, 미래 수익이나 반복 가능성을 보장하지 않습니다.
